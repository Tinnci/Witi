# Product Overview

A Sims 1-inspired life simulation game built with Dart and Flutter, featuring 2.5D isometric graphics and autonomous character behavior.

## Core Features
- 2.5D isometric view with tile-based world
- Need-based AI system (hunger, hygiene, social, etc.)
- Interactive objects with advertisement-scoring system
- Character autonomy with player-directed actions
- Cross-platform deployment (Windows, macOS, Linux, Web, Mobile)

## Key Design Principles
- Lightweight and performant for single-developer workflow
- Modular simulation engine separate from rendering
- Data-driven object behaviors and interactions
- Hot-reload friendly development experience
